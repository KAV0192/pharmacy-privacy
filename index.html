Политика конфиденциальности

Приложение «Аптечка+» · обновлено 30 июня 2026 г.

Коротко

«Аптечка+» хранит все ваши данные только на вашем устройстве. Приложение не требует регистрации, не собирает персональные данные и не передаёт ваши данные (включая сведения о здоровье) на серверы разработчика или третьим лицам.

1. Общие положения

Настоящая Политика описывает, как мобильное приложение «Аптечка+» (далее — «Приложение») обращается с данными пользователя. Используя Приложение, вы соглашаетесь с условиями этой Политики. Приложение разрабатывается частным разработчиком; контакт для связи указан в конце документа.

2. Какие данные и где хранятся

Все данные, которые вы вносите, сохраняются локально на вашем устройстве (во внутренней базе данных приложения) и не покидают его. К таким данным относятся:

  • аптечки, лекарства и их параметры (название, форма, количество, срок годности, заметки);
  • курсы приёма и расписание напоминаний;
  • журнал приёма лекарств;
  • показатели здоровья, которые вы вносите вручную (например, давление, пульс, вес, температура, сахар, сатурация).

Разработчик не имеет доступа к этим данным и не получает их копий.

3. Разрешения устройства

Камера

Используется только для сканирования штрихкодов упаковок лекарств. Распознавание выполняется на самом устройстве. Приложение не сохраняет фотографии и не передаёт изображения с камеры куда-либо.

Уведомления

Используются для локальных напоминаний о приёме лекарств. Содержимое напоминаний формируется на устройстве и никуда не отправляется.

Доступ в интернет

Приложение обращается в интернет только для загрузки служебной информации — конфигурации оформления и изображений (например, рекламного баннера внутри приложения). При этом ваши личные данные и сведения о здоровье не передаются.

4. Передача данных и интернет-запросы

Приложение не собирает персональные данные и не передаёт ваши данные третьим лицам. В частности:

  • нет регистрации, аккаунтов и облачной синхронизации;
  • нет систем аналитики, статистики и сбора сведений о сбоях (телеметрии);
  • не используются сторонние рекламные сети и рекламные идентификаторы; реклама, если показывается, представляет собой баннер, загружаемый приложением, и не отслеживает пользователя.

При загрузке указанных в п. 3 служебных файлов и изображений Приложение делает обычный сетевой запрос к серверам в интернете (включая хостинг разработчика). Как и при любом обращении к сайту, принимающему серверу может быть технически виден IP-адрес и общие сведения об устройстве. Эти запросы не содержат внесённых вами данных и не используются для вашей идентификации или построения профиля.

5. Хранение и удаление данных

Поскольку данные хранятся только на устройстве, вы полностью контролируете их. Приложение не создаёт облачных резервных копий. Чтобы удалить все данные Приложения, достаточно удалить Приложение с устройства (или очистить его данные в настройках системы). После этого восстановить данные будет невозможно.

6. Дети

Приложение не предназначено для самостоятельного использования детьми и не собирает данные намеренно у детей. Приложение в принципе не собирает персональных данных от кого-либо.

7. Назначение приложения

«Аптечка+» — это инструмент для учёта домашних лекарств, напоминаний и ведения личных записей о показателях здоровья. Приложение не является медицинским изделием, не ставит диагнозы и не заменяет консультацию врача.

8. Изменения политики

Политика может обновляться при изменении функций Приложения (например, при подключении новых сервисов). Актуальная версия всегда доступна на этой странице; дата последнего обновления указана вверху.
